# 偶艺云承 - 用户手册

---

## 一、平台概述

### 1.1 平台简介

**偶艺云承**是一个综合性的木偶戏数字文化平台，旨在通过现代信息技术手段，系统性地保护、传承和创新中国传统木偶艺术。平台融合了数字典藏、AI创作、沉浸式体验等多种功能，为用户提供全方位的木偶戏文化服务。

### 1.2 平台使命

- **保护**：数字化保存珍贵的木偶戏文化遗产
- **传承**：让传统木偶艺术在新时代焕发活力
- **创新**：探索木偶艺术与现代科技的融合
- **传播**：让更多人了解和喜爱木偶戏

### 1.3 核心特色

| 特色功能 | 描述 |
|---------|------|
| 数字典藏 | 收录全国各地木偶戏流派的详细资料 |
| AI创作工具 | 利用人工智能辅助生成木偶形象 |
| 沉浸式体验 | VR/AR技术打造全新观演方式 |
| DIY工坊 | 自由创作专属木偶形象 |
| 在线剧场 | 高清演出视频在线观看 |

## 二、系统要求

### 2.1 硬件要求

- **桌面端**：
  - CPU：Intel i5 或 AMD 同等性能处理器
  - 内存：8GB 及以上
  - 显卡：支持 WebGL 的独立显卡
  - 屏幕分辨率：1280×720 及以上

- **移动端**：
  - 操作系统：iOS 13.0+ 或 Android 8.0+
  - 内存：4GB 及以上
  - 存储空间：至少 100MB 可用空间

### 2.2 软件要求

- **浏览器**：
  - Chrome 80+
  - Firefox 75+
  - Safari 13+
  - Edge 80+

### 2.3 网络要求

- 建议使用 WiFi 或 4G/5G 网络
- 最低带宽：2Mbps
- 高清视频观看：10Mbps 及以上

## 三、注册与登录

### 3.1 用户注册

#### 注册流程

1. **访问注册页面**
   - 打开偶艺云承官网首页
   - 点击右上角「注册」按钮
   - 或直接访问：`/register`

2. **填写注册信息**
   - **邮箱地址**：输入有效的电子邮箱
   - **设置密码**：6-20位字符，建议包含大小写字母和数字
   - **确认密码**：再次输入相同密码
   - **昵称**：设置您的显示名称
   - **验证码**：输入图片验证码

3. **完成注册**
   - 仔细阅读《用户服务协议》和《隐私政策》
   - 勾选同意协议
   - 点击「立即注册」按钮

#### 注意事项

- **邮箱唯一性**：每个邮箱只能注册一个账号，重复邮箱会提示「该邮箱已注册」
- **密码安全**：请设置安全强度较高的密码，建议定期更换
- **验证码有效期**：图片验证码有效期为5分钟，过期需刷新重新获取

### 3.2 用户登录

#### 登录流程

1. **访问登录页面**
   - 点击首页右上角「登录」按钮
   - 或直接访问：`/login`

2. **输入登录信息**
   - **邮箱地址**：注册时使用的邮箱
   - **密码**：设置的登录密码

3. **完成登录**
   - 点击「登录」按钮
   - 登录成功后自动跳转到个人中心

#### 登录状态管理

- **自动登录**：勾选「记住我」可保持7天登录状态
- **安全退出**：点击右上角头像 → 选择「退出登录」
- **多设备登录**：支持多设备同时登录，登录状态相互独立

### 3.3 密码找回

#### 找回流程

1. **进入找回页面**
   - 在登录页面点击「忘记密码」链接
   - 或直接访问：`/forgot-password`

2. **验证身份**
   - 输入注册邮箱
   - 输入验证码

3. **重置密码**
   - 系统发送重置链接到注册邮箱
   - 点击链接进入密码重置页面
   - 设置新密码并确认

#### 注意事项

- **邮件有效期**：重置链接有效期为24小时
- **多次尝试**：若未收到邮件，可检查垃圾邮件箱或重新发送
- **安全提醒**：建议在安全环境下进行密码重置操作

### 4.3 偶之艺

#### 功能概述

**偶之艺**是木偶技艺数字化传承模块，通过AI学习助手和智能评测功能，帮助用户学习和提升木偶操控技艺。

#### 核心功能

##### 4.3.1 AI学习助手

**功能概述**：分阶段匹配不同学习层级，专注操控技巧训练

**课程体系**：

| 课程名称 | 难度 | 类型 | 内容简介 |
|----------|------|------|----------|
| 提线木偶基础操控 | 入门 | 提线木偶 | 手部动作规范与基础操控训练 |
| 杖头木偶面部表情训练 | 进阶 | 杖头木偶 | 头部转动与表情变化技巧 |
| 布袋木偶手势操控技法 | 进阶 | 布袋木偶 | 手指灵活度训练与手势操控 |
| 铁枝木偶动作协调性训练 | 进阶 | 铁枝木偶 | 铁枝操控与动作协调配合 |
| 杖头木偶走位 | 高级 | 综合技巧 | 舞台走位技巧训练 |
| 多人协作操控训练 | 高级 | 协作技巧 | 多人配合协调训练 |

**学习流程**：

1. **选择课程**：从课程列表中选择感兴趣的课程
2. **观看教学**：观看大师标准动作视频
3. **练习操作**：跟随视频进行实操练习
4. **智能评测**：上传练习视频进行AI评测

##### 4.3.2 智能评测系统

**功能概述**：上传操控视频，AI将评测动作轨迹，与大师标准动作对比，生成精准纠错报告

**评测流程**：

1. **上传视频**：
   - 大师标准动作视频（系统预置或上传）
   - 用户训练视频（用户上传）

2. **AI分析**：
   - 动作轨迹追踪
   - 与标准动作比对
   - 生成分析报告

3. **查看结果**：
   - 准确率统计
   - 相似度对比
   - 动作完成度
   - 流畅度评分

4. **获取建议**：
   - 身体部位分析（手部、手腕、手臂、躯干、腿部）
   - 动作分解分析（准备动作、提线控制、动作连贯、收尾动作）
   - 改进建议
   - 个性化训练计划

**使用步骤**：

1. 点击课程卡片的「智能评测」按钮
2. 或进入智能评测区域
3. 上传大师标准动作视频（可选择预置视频）
4. 上传用户训练视频
5. 点击「上传视频」按钮
6. 点击「开始评测」按钮
7. 等待AI分析完成
8. 查看分析报告和改进建议

**注意事项**：
- 视频格式支持：MP4、AVI、MOV等常见格式
- 视频时长建议：10-60秒
- 上传视频大小限制：500MB以内
- 分析时间：约30秒-2分钟

### 4.5 AI木偶画师

#### 功能概述

利用人工智能技术生成独特的木偶形象

#### 使用流程

1. **输入创作描述**
   - 在文本框中描述想要生成的木偶形象
   - 支持中文和英文描述
   - 建议描述包含：角色类型、风格、服饰特点等

2. **选择风格**
   - 传统风格：古典戏曲风格
   - 现代风格：简约现代设计
   - 卡通风格：可爱Q版形象

3. **生成图片**
   - 点击「生成」按钮
   - 等待AI处理（约10-30秒）
   - 生成4张不同风格的图片

4. **选择与保存**
   - 点击喜欢的图片查看大图
   - 支持下载原图
   - 可再次生成或调整描述

#### 使用技巧

- **描述越详细越好**：包含颜色、服饰、表情、背景等元素
- **尝试不同风格**：切换风格获得多样化结果
- **保存喜欢的作品**：点击下载按钮保存到本地

#### 常见问题

- **生成失败**：网络问题或服务器繁忙，稍后重试
- **结果不满意**：调整描述词或更换风格
- **图片有水印**：生成的图片带有平台水印

## 七、常见问题

### Q1：为什么页面加载缓慢？

**原因分析**：
- 网络连接不稳定
- 浏览器缓存过多
- 设备性能不足

**解决方法**：
- 检查网络连接，切换到稳定网络
- 清除浏览器缓存（Ctrl+Shift+Del）
- 关闭其他占用资源的应用
- 升级浏览器到最新版本

### Q2：注册时提示邮箱已存在怎么办？

**原因分析**：该邮箱已被注册过账号

**解决方法**：
- 使用其他邮箱注册
- 尝试找回密码（可能忘记已有账号）
- 联系客服核实账号情况

### Q3：AI生成图片失败怎么办？

**原因分析**：
- 网络连接问题
- 服务器繁忙
- 描述内容不符合规范

**解决方法**：
- 检查网络连接
- 稍后重试
- 简化描述内容，避免敏感词汇

### Q4：DIY创作时素材无法添加怎么办？

**原因分析**：
- 浏览器兼容性问题
- JavaScript未启用
- 页面加载不完整

**解决方法**：
- 刷新页面重新加载
- 更换浏览器（推荐Chrome）
- 确保JavaScript已启用

### Q5：视频无法播放怎么办？

**原因分析**：
- 网络带宽不足
- 浏览器不支持视频格式
- 视频资源暂时不可用

**解决方法**：
- 切换到更快的网络
- 升级浏览器版本
- 尝试其他视频或稍后再试

### Q6：如何下载视频？

**说明**：
- 部分视频受版权保护，不支持下载
- 可下载的视频会显示下载按钮
- 移动端支持离线缓存功能
